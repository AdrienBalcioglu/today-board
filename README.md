# Today Board

Three priorities for the day, no more. The board starts empty every morning.

**[Website](https://adrienbalcioglu.github.io/today-board/about.html)** · **[Open the app](https://adrienbalcioglu.github.io/today-board/)**

## Features

- Three slots, on purpose
- A new day archives the previous one and offers what was left undone
- History of past days and a streak of days fully done
- Works if the tab stays open overnight

## Usage

Open `index.html` in a browser. There is nothing to install and nothing to build.

Everything is saved in the browser's local storage. No account, no API key, no server: nothing leaves your machine.

## Stack

HTML, CSS and JavaScript in a single file. No dependency.
